# Kamila Meshaj Portfolio

Production portfolio website for Kamila Meshaj, Content Creator & Social Media Manager.

## Tech

- Next.js
- TypeScript
- Tailwind CSS

## Local Development

```powershell
npm install
npm run dev
```

## Validation

```powershell
npm run lint
npm run build
```

## Environment

Set `NEXT_PUBLIC_SITE_URL` to the deployed production origin before the final production build.
